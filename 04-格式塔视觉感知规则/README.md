# 04 格式塔视觉感知规则｜视觉组织原理

本专题研究读者怎样**把元素归成一组、沿轮廓追踪关系、补全整体、辨认主体和背景**。在分析信息图时，先记录读者从画面里容易组织出什么关系，再用数据、图例或标签核对实际关系。例如，点的位置靠近，读者容易把它们分在一起。数据上是否同组要另查类别字段。

## 课件依据与术语

- 《信息图形设计导论》第 3 页将格式塔心理学放在认知科学的学习框架中。逐项定义和教学示例主要参考《交互信息设计（编辑版）》第 33–42 页，图底关系也参照第 30、45 页。图示根据课件的讲法与研究文献重绘。
- 第 40 页「同步原则」的配图强调方向一致。此处用**共同命运**记录同向运动，用**同步性**记录同一时刻发生变化。第 41 页例图使用边界包围，按**共同区域**登记。
- 本索引采用 **13 项视觉组织原理或概念，加 1 项经验识别扩展**。第 42 页的异质同构以软盘图标为例，适合讨论熟悉形象与符号意义的对应。学术分类和后续分组线索参考[Wagemans 等，视觉分组与图底组织综述](https://doi.org/10.1037/a0029333)。

## 怎样用于案例分析

1. 写出读者要做的动作，例如查出同一组、从线的起点找到终点，或在地图上定位重点。
2. 标出具体证据，例如组内距离、背景边界、连续轮廓、明暗差异或状态变化时间。
3. 核对数据中的关系与读者可能感知的关系。把能凭图定位的支持证据写清，未经读者测试的效果标为「据图判断」。
4. 做一个对照版本，每次优先改变一种组织线索。记录读者如何分组、是否配错值、用时及理由。
