## 分类原则
- 数据逻辑回答“信息如何组织”：编年、层级、编目、字母表、地理。
- 表现形式回答“信息如何视觉化”：混合型、文字／列表型、时间轴型等。
- 一个案例可以有一个主数据逻辑和多个表现形式标签，不重复存储同一案例。
- 理论文档不存放图片，通过文本链接引用案例分析。
