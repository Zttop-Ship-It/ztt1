## 分类原则
- 数据逻辑回答“信息如何组织”：编年、层级、编目、字母表、地理。
- 表现形式回答“信息如何视觉化”：混合型、文字／列表型、时间轴型等。
- 一个案例可以有一个主数据逻辑和多个表现形式标签，不重复存储同一案例。
- 理论文档不存放图片，通过文本链接引用案例分析。

## 案例驱动更新机制
每新增案例：登记来源与版权 → 完成案例分析 → 判定主数据逻辑及表现形式 → 在适用总文档添加链接 → 从证据中提炼原则并更新修订记录。无案例支持的内容标记为“待案例验证”，不得写成已证实规律。

## 证据与版权约定
原作者、出处、许可未核实的图像标记“未核实”，不得声称已获授权；无法辨认的文字和数字不补写为事实；统计判断须有数据、单位、样本范围及来源依据。
