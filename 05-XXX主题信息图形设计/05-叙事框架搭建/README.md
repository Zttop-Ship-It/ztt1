# 05 叙事框架搭建

从基础数据集里挑出能回答同一个读者问题的几列。**一个叙事模块对应一个明确问题和一组证据**。

| 读者问题 | 选用字段 | 形成的叙事主题 | 必要口径 |
| --- | --- | --- | --- |
| 这些地点在哪里？ | 地点名称＋经度＋纬度 | 地图上的地点分布 | 坐标系、区域范围 |
| 哪些地点的 GDP 较高？ | 地点名称＋GDP 数值＋单位＋统计年份 | 同一时期各地点 GDP 的比较 | 币种、单位、时期、统计定义 |
| 事件按什么顺序发生？ | 日期＋事件名称＋事件说明 | 关键事件的时间顺序 | 日期精度、缺失时点 |

## 读者阅读路径

| 顺序 | 模块主题 | 读者要找的答案 | 字段或证据位置 | 与下一模块的关系 |
| ---: | --- | --- | --- | --- |
| 1 | 从总览进入 | | | |
| 2 | 查看关键比较或空间分布 | | | |
| 3 | 补充细节与来源 | | | |

模块可以顺读，也可以通过目录、地图标记或小标题跳读。记录读者看到结论后可以到哪里核对。下一步进入[视觉编码](../06-视觉编码/README.md)。
