# 02 主题内容分析

## 和大模型一起确定分析方向

将前期调研结果、读者问题及几行代表性数据贴给大模型，请它依次提出判断、证据和待核实项。确认后把决定填进表里，并保留关键对话摘要。

> 我的选题是〔主题〕，目标读者是〔读者〕，他们最想回答〔问题〕。以下是已经知道的数据对象、字段和关系〔填入样例〕。请先判断主数据逻辑并指出依据，再建议主标签、辅助标签和视觉风格。逐项说明这种形式怎样帮助读者，以及需要哪些数据才能成立。请标出资料缺口。

| 判断层次 | 候选与判断依据 | 最终决定 |
| --- | --- | --- |
| 五大主数据逻辑 | 时间顺序→编年型。上下位或包含→层级型。类别与属性→编目型。字母键检索→字母表型。地点、区域、路线→地理图型 | |
| 主表现标签 | 关注读者要做什么。浏览条目可考虑文字／列表型，照片是主要证据时考虑图片式，阅读顺序以年份为主时考虑时间轴型 | |
| 辅助标签 | 比较、流程、地标等，按图内实际的辅助模块选择 | |
| 词云是否适合 | 先确认是否有语料、分词与词频或权重。要精确核对次数时记录排序或明示数值的需求 | |
| 视觉风格 | 平面、照片或混合。说明风格是否有助于识别对象、看清结构或核对证据 | |
| 数据缺口 | 缺什么字段、观察范围、素材来源或授权信息 | |

同一案例可同时填写「编目型」「图片式」「照片风格」。三项分别回答数据怎样组织、内容怎样呈现、画面如何表现。
