# 03 数据搜集

| 来源类型 | 收集什么 | 同时记录 |
| --- | --- | --- |
| 公用数据集 | 开放统计、开放地图、政府或机构公开表格 | 发布机构、链接、版本、统计期间、授权 |
| 文本文献 | 书籍、论文、报道、档案或访谈记录中能核查的信息 | 作者、出处、页码或章节、原文与转录值 |
| 自建数据集 | 自行清点、观察、测量、访谈或按规则编码的记录 | 采集日期、对象范围、采样规则、记录人、缺失值 |
