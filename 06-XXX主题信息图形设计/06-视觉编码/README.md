# 06 视觉编码

这一阶段偏重设计表达。把每个数据字段或叙事任务对应到具体的标记、版面与文字处理，记录读者怎样识别和读数。

| 视觉手段 | 可以承担的任务 | 核对方式 |
| --- | --- | --- |
| 点 | 标记地点、事件、观测值 | 点位与数据坐标或刻度相符 |
| 线 | 表示路径、趋势、连接、引注 | 核对端点、方向、缺测和线型含义 |
| 面 | 表示区域、份额、背景分组 | 定量面积要说明比例规则，背景面写明分组作用 |
| 体 | 说明空间结构与层次 | 核查透视遮挡和大小误读 |
| 色彩 | 区分类别、表示量级、突出重点 | 类别色与连续色阶各有图例，另用标注帮助识别 |
| 行距、字距 | 分隔信息组、提高辨读性、建立文字层级 | 比较组内与组间间距，避免把标签配到相邻对象 |
| 图像、图形 | 识别真实对象、提供细节或示意关系 | 写明照片、插画、剪影分别承担的角色 |
| 统计图形 | 比较量值、分布、时间变化或关系 | 核对轴、基线、分母、单位与字段映射 |
| ISO 图形与标准图符 | 辅助识别概念、对象或动作 | 若采用标准符号，记录来源和语义。若用 ISOTYPE 重复图符计量，另记每枚图符的单位 |
