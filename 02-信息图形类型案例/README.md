# 02-信息图形类型案例｜按标签分文件夹

**管理原则：先判断01基础数据逻辑，再判02表现标签，随后从具体案例提炼视觉编码、叙事、风格特性、制作方法与制作流程；一类一个文件夹，一张案例图一份独立分析报告。** 本目录按上传课件第22–38页所列16个标签建立；每个类别均有 `00-类型说明.md`、`01-案例图/`、`02-案例分析/`。

## 文件配对规则
- `类型文件夹/01-案例图/CASE-001-作品名.png`
- `类型文件夹/02-案例分析/CASE-001-作品名分析报告.md`

文件通过**同一个 CASE-ID**一一关联；分析报告写明相对图像路径、作者、原始出处、许可、数据结构、统计图形／方法、视觉编码、信息架构和叙事架构。新增案例时同步更新各类 `00-类型说明.md`，并按需反哺 `01-信息图形数据逻辑` 的理论总文档；理论文档仅引用链接，不保存图片。

## 第三讲课件案例图
上传课件提供了类别和视觉案例线索，但作品原作者、原图来源和可公开传播许可需要逐一核实。[第三讲课件案例](./第三讲课件案例索引.md)已按主标签整理。共 99 条案例记录、343 行图面结构观察和 296 行补充转录、图符计数及推导。本批 99 张案例图提取自所提供的 PDF，依案例号归入各主标签的 `01-案例图` 文件夹。第三方作品的转载许可待核实。 初始教学标签线索可在各子目录的课件示例索引查看。

## 核心工作顺序（优先遵守）

1. **01主逻辑**：按数据关系在编年／层级／编目／字母表／地理中选择主归属。
2. **02标签**：按具体呈现方式选择主表现形式及辅助标签，ISOTYPE另作方法标签。
3. **案例深析**：分别分析A数据、B统计、C视觉编码、D信息框架、E叙事框架。
4. **制作知识**：总结该案例的表现特性、可复用的制作方法与可重建制作步骤，说明证据和适用边界。
5. **双向回写**：数据关系和理论原则写01；编码、叙事、风格和制作流程写02；更新CASE索引与修订记录。
