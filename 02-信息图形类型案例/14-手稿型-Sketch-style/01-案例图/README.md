# 手稿型｜案例图

此目录为该标签下**多个独立案例图片**的存放位置。

## 命名及对应规则
- 图片：`CASE-ID-案例简称.png`（或 .jpg/.svg）
- 配属说明：`../02-案例分析/CASE-ID-案例简称分析报告.md`
- 每张图片必须拥有同一 CASE-ID 的独立报告，图片和文档不能混用编号。
- 图片来源与授权必须明确：作者／原始URL／采集日期／版权状态。

## 当前状态
来自用户上传课件的图片仅供定位研究案例，**课件中第三方作品版权与公开发布许可未核实，尚未上传案例图片**。不得以课件页面截图冒充已获授权的原图。
